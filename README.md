# Architectural Real Estate Property Developer Portfolio

> **Website 02 — Premium Property Developer Demo Portfolio**  
> An award-winning architectural real estate portfolio demo crafted with an asymmetrical editorial design, strict two-color system, and responsive layout.

---

## 01. Visual & Architectural Philosophy

* **Contemporary Architectural Editorial Design:** Asymmetrical grid, structured white-space, magazine-spread visual storytelling.
* **Strict Two-Color System:**
  * **Primary (Deep Teal):** `#035759`
  * **Secondary (Warm Ivory):** `#EDEAE3`
  * **Zero 3rd Colors:** No gradients, no glowing effects, no colorful shadows, no background tints. Only opacities derived from Deep Teal and Warm Ivory.
* **Typography:**
  * Headings & Labels: `Manrope` (Modern geometric sans-serif)
  * Body & Specifications: `Inter` (High-legibility sans-serif)

## 03. Interactive Features

* **Dynamic Theme Observer:** Sticky header and floating navigation rail seamlessly switch between Deep Teal and Warm Ivory based on section scroll position.
* **Floating 5-Item Navigation:**
  * `01 — WHO WE ARE`
  * `02 — OUR SERVICES`
  * `03 — PROJECTS`
  * `04 — OUR PROCESS`
  * `05 — CONTACT`
* **Expandable Property Collections:** Interactive accordion for Townhouses and Villas with smooth height transitions and specs overview.
* **Architectural Lightbox:** Full-screen inspection modal for gallery photographs with caption metadata.
* **Project Progress Timeline:** Modal displaying masterplan construction milestones and delivery dates.
* **Validated Project Enquiry Form:** Complete client-side validation with responsive feedback states.
* **Full Mobile Responsiveness:** Converts vertical desktop typography into clean horizontal titles, stacks gallery panels, and activates an accessible full-screen navigation drawer.
